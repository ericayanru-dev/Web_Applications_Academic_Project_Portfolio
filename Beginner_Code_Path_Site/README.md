# Beginner Code Path

## Overview

**Beginner Code Path** is a multi-page educational website designed to guide beginners through the fundamentals of programming and web development. The project provides structured learning paths, curated external resources, and hands-on exercises for multiple languages, all within a clean, responsive, and accessible interface.

This project demonstrates core front-end development skills using **HTML, CSS, and JavaScript** and follows best practices suitable for an academic web development course and a professional GitHub portfolio.

---

## Live Pages Included

The site consists of multiple interconnected pages:

* **Home (`index.html`)** – Introduction to the Beginner Code Path and featured learning areas
* **Learn (`learn.html`)** – Central hub for selecting a programming language
* **HTML (`html.html`)** – Beginner HTML concepts and exercises
* **CSS (`css.html`)** – Styling, layout, and responsive design basics
* **JavaScript (`javascript.html`)** – Interactivity, DOM manipulation, and events
* **Python (`python.html`)** – Beginner scripting and logic fundamentals
* **C# (`csharp.html`)** – Object-oriented programming basics
* **SQL (`sql.html`)** – Database querying and data management fundamentals

Each learning page follows a consistent layout:

* Introduction section
* “What You’ll Learn” list
* Curated external resources
* A hands-on practice exercise

---

## Features

### Navigation & Layout

* Responsive navigation menu with mobile toggle
* Consistent header and footer across all pages
* CSS Grid and Flexbox for modern layouts
* Fully responsive design using media queries

### Interactivity (JavaScript)

* Mobile navigation toggle
* Dynamic FAQ section generated from JavaScript data
* Contact form handling with `localStorage`
* Automatic year update in the footer

### Accessibility & Best Practices

* Semantic HTML structure
* Meaningful `alt` text for images
* Logical heading hierarchy
* ARIA attributes where appropriate

## Technologies Used

* **HTML5** – Semantic structure and content
* **CSS3** – Custom properties, Grid, Flexbox, responsive design
* **JavaScript (Vanilla)** – DOM manipulation, event handling, localStorage
* **Google Fonts** – Poppins and Roboto
